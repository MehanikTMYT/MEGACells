# MEGA Cells

![Логотип MEGA Cells](assets/logo.png)

## Введение

**MEGA Cells** — аддон для Applied Energistics 2, добавляющий более высокие
уровни хранения вместимостью от **1M** до **256M**, а также особые
возможности: специализированные ячейки хранения и дополнительные инструменты для работы с ними.

Для новых уровней хранения нужны новые материалы. При подготовке
инфраструктуры MEGA прежде всего потребуется много <ItemLink id="ae2:sky_stone_block" />: вместе с
железом и <ItemLink id="ae2:charged_certus_quartz_crystal" /> он превращается в **небесные стальные слитки**.
Но вода для обработки металла не подойдёт —
для плавления и преобразования понадобится гораздо более горячая жидкость.
